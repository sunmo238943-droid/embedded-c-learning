## 3. 逻辑运算符

学习了：

```c
&&    // 并且
||    // 或者
!     // 取反
```

对应 Python：

```text
&&  → and
||  → or
!   → not
```

例如判断电压是否位于正常范围：

```c
if (voltage >= 3.0f && voltage <= 5.0f)
{
    printf("Voltage normal\n");
}
```

## 4. switch / case

学习了固定离散值的分支判断：

```c
switch (mode)
{
    case 1:
        printf("Manual mode\n");
        break;

    case 2:
        printf("Automatic mode\n");
        break;

    default:
        printf("Invalid mode\n");
}
```

理解了：

```text
case     → 匹配具体值
break    → 结束当前分支
default  → 没有 case 匹配时执行
```

如果省略 `break`，可能发生 fall-through，继续执行后面的 `case`。
